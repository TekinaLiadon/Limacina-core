# Документация Limacina

Limacina это бекенд для Minecraft в одном процессе. Он закрывает четыре задачи:

- JWT-авторизация для лаунчера и админ-панели: регистрация, вход, refresh-токены, смена пароля.
- Протокол Yggdrasil (authlib-injector) для входа в игру, скины и плащи загружаются прямо из клиента.
- Раздача контента лаунчера: релизы для tauri-plugin-updater, манифест файлов игры.
- Панель управления: пользователи, роли, логи, RCON-консоль, перезапуск и пересборка сервера.

Стек: NestJS поверх Fastify, рантайм Bun (не Node). Хранилище выбирается одной переменной окружения: память для разработки, PostgreSQL или MariaDB для прода. Сборка даёт самодостаточный бинарник, рядом нужен только каталог с `public/`, ключами и env.

## Про API-документацию

Спецификация OpenAPI генерируется из кода на лету, декораторами контроллеров и DTO. Живой UI на Scalar открывается на `/docs`, машинная спека лежит на `/openapi.json`. Списка эндпоинтов в этих файлах нет намеренно: он устарел бы при первой же правке. [api.md](api.md) объясняет, как читать спеку, и описывает то, чего в ней не видно: роли, лимиты, формат ошибок.
